# 迭代执行指令

## 当前任务
你正在进行 AITeam 项目的**自动迭代冲刺**。

## 迭代协议

### Step 1: 选择需求
从需求池中选择一个功能实现。优先级：
1. 用户可见的 UI 增强
2. 用户体验改进
3. 性能优化
4. 代码质量提升

### Step 2: 实现功能
- 遵循项目现有架构和代码风格
- 复用现有组件和 hooks
- 保持代码简洁，不过度设计

### Step 3: 验证闭环
- 运行相关测试
- 检查 TypeScript 编译
- 确保没有引入新的错误

### Step 4: 记录成果
更新 `.claude/auto-iteration/iteration-log.md`：
- 记录实现了什么功能
- 更新统计面板
- 标记 PUA 触发点

## 执行指令
每次迭代，选择一个未完成的需求，实现它，测试它，记录它。

> **P8 底线**: 没有测试验证的交付不叫交付，叫自嗨。每次迭代必须跑通验证。

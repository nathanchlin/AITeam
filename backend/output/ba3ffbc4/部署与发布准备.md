# 消消乐游戏部署与发布准备方案

## 1. 服务器环境设置

### 硬件要求
- CPU: 2核心以上
- 内存: 4GB以上
- 存储: 20GB以上可用空间
- 网络: 稳定的互联网连接

### 软件环境
- 操作系统: Ubuntu 20.04 LTS 或 CentOS 8
- Web服务器: Nginx 1.18+
- 数据库: MySQL 8.0+ 或 PostgreSQL 12+
- 运行时环境:
  - Node.js 14+ (如果使用Node.js后端)
  - Python 3.8+ (如果使用Python后端)
  - PHP 7.4+ (如果使用PHP后端)
- 缓存: Redis 6.0+

### 环境配置步骤
1. 更新系统: `sudo apt update && sudo apt upgrade -y`
2. 安装Nginx: `sudo apt install nginx -y`
3. 安装数据库: `sudo apt install mysql-server -y`
4. 安装Node.js (示例): `curl -fsSL https://deb.nodesource.com/setup_14.x | sudo -E bash - && sudo apt-get install -y nodejs`
5. 安装PM2 (进程管理器): `sudo npm install -g pm2`
6. 配置防火墙: `sudo ufw allow 'Nginx Full'`

## 2. 应用部署流程

### 文件结构准备
```
/消消乐游戏/
├── frontend/          # 前端代码
├── backend/           # 后端代码
├── database/          # 数据库脚本
├── docs/              # 文档
├── scripts/           # 部署脚本
└── config/            # 配置文件
```

### 部署步骤
1. 上传代码到服务器
2. 安装依赖:
   - 前端: `npm install` 或 `yarn install`
   - 后端: 根据框架安装依赖
3. 配置环境变量:
   ```bash
   # 创建环境变量文件
   nano .env
   ```
   示例环境变量:
   ```
   NODE_ENV=production
   PORT=3000
   DB_HOST=localhost
   DB_USER=game_user
   DB_PASSWORD=secure_password
   DB_NAME=match_game
   ```
4. 运行数据库迁移: `npm run migrate` 或根据框架命令
5. 构建前端资源: `npm run build`
6. 启动应用: `pm2 start app.js --name match-game`

# Python开发环境配置指南

## 1. Python环境安装

### Windows系统
1. 访问Python官网 [python.org](https://www.python.org/downloads/)
2. 下载最新稳定版Python安装包
3. 运行安装程序，勾选"Add Python to PATH"选项
4. 完成安装后，打开命令提示符验证安装：
   ```bash
   python --version
   ```

### macOS系统
1. 使用Homebrew安装：
   ```bash
   brew install python
   ```
2. 或者从官网下载安装包并按照提示安装

### Linux系统
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# CentOS/RHEL
sudo yum install python3 python3-pip
```

## 2. 配置pytest和unittest框架

### 安装pytest
```bash
pip install pytest
```

### 验证pytest安装
```bash
pytest --version
```

### 创建测试目录结构
```
project/
├── src/
│   └── your_module.py
├── tests/
│   ├── __init__.py
│   ├── test_unittest.py
│   └── test_pytest.py
└── requirements.txt
```

### unittest示例 (tests/test_unittest.py)
```python
import unittest
from src.your_module import add, multiply

class TestMathFunctions(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(2, 3), 5)
        self.assertEqual(add(-1, 5), 4)
        
    def test_multiply(self):
        self.assertEqual(multiply(3, 4), 12)
        self.assertEqual(multiply(0, 5), 0)

if __name__ == '__main__':
    unittest.main()
```

### pytest示例 (tests/test_pytest.py)
```python
from src.your_module import add, multiply

def test_add():
    assert add(2, 3) == 5
    assert add(-1, 5) == 4

def test_multiply():
    assert multiply(3, 4) == 12
    assert multiply(0, 5) == 0

# 使用pytest的参数化功能
import pytest

@pytest.mark.parametrize("a,b,expected", [
    (1, 2, 3),
    (-1, 5, 4),
    (0, 0, 0)
])
def test_add_parametrized(a, b, expected):
    assert add(a, b) == expected
```

### 运行测试
```bash
# 运行所有测试
pytest

# 运行特定测试文件
pytest tests/test_unittest.py

# 运行特定测试函数
pytest tests/test_pytest.py::test_add

# 运行unittest测试
python -m unittest tests.test_unittest
```

## 3. 开发环境配置

### VS Code配置

1. 安装VS Code
2. 安装Python扩展：
   - 打开VS Code
   - 点击扩展图标 (Ctrl+Shift+X)
   - 搜索"Python"，安装Microsoft官方Python扩展

3. 创建VS Code工作区设置 (.vscode/settings.json)：
```json
{
    "python.testing.pytestEnabled": true,
    "python.testing.unittestEnabled": true,
    "python.linting.enabled": true,
    "python.linting.pylintEnabled": true,
    "python.formatting.provider": "black",
    "editor.formatOnSave": true,
    "python.analysis.typeCheckingMode": "basic"
}
```

4. 创建launch.json用于调试：
```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Current File",
            "type": "python",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal",
            "justMyCode": true
        },
        {
            "name": "Python: Pytest",
            "type": "python",
            "request": "launch",
            "module": "pytest",
            "args": [
                "${file}"
            ],
            "console": "integratedTerminal",
            "justMyCode": false
        }
    ]
}
```

### PyCharm配置

1. 安装PyCharm (Community或Professional版)
2. 创建新项目，选择"Pure Python"
3. 配置解释器：
   - File > Settings > Project > Python Interpreter
   - 点击齿轮图标 > Add > 选择已安装的Python解释器

4. 配置测试运行器：
   - File > Settings > Tools > Python Integrated Tools
   - 在"Testing"部分选择pytest和unittest

5. 配置代码风格：
   - File > Settings > Editor > Code Style > Python
   - 选择PEP 8或其他你喜欢的风格

## 4. 开发环境初始化脚本

创建一个setup.py文件来简化环境设置：
```python
from setuptools import setup, find_packages

setup(
    name="your_project",
    version="0.1",
    packages=find_packages(),
    install_requires=[
        "pytest",
        "pytest-cov",
        "black",
        "flake8",
    ],
    python_requires=">=3.7",
    entry_points={
        "console_scripts": [
            "your-command=src.your_module:main",
        ],
    },
)
```

创建requirements.txt文件：
```
pytest>=6.0.0
pytest-cov>=2.10.0
black>=21.0.0
flake8>=3.8.0
```

安装依赖：
```bash
pip install -r requirements.txt
```

## 5. 开发环境验证

创建一个简单的测试文件来验证环境是否正确配置：

```python
# src/verify_env.py
def add(a, b):
    """简单的加法函数"""
    return a + b

def multiply(a, b):
    """简单的乘法函数"""
    return a * b

if __name__ == "__main__":
    print(f"2 + 3 = {add(2, 3)}")
    print(f"3 * 4 = {multiply(3, 4)}")
```

运行验证：
```bash
# 直接运行
python src/verify_env.py

# 使用pytest
pytest tests/

# 使用unittest
python -m unittest tests.test_unittest
```

## 6. 开发工作流建议

1. **编码规范**：
   - 使用PEP 8作为基本编码规范
   - 使用black进行代码格式化
   - 使用flake8进行代码检查

2. **测试策略**：
   - 为所有公共函数编写单元测试
   - 保持测试覆盖率在80%以上
   - 使用pytest的参数化功能测试边界情况

3. **版本控制**：
   - 使用Git进行版本控制
   - 创建.gitignore文件排除不必要的文件
   - 遵循语义化版本控制

4. **持续集成**：
   - 考虑使用GitHub Actions或Travis CI
   - 自动运行测试和代码检查

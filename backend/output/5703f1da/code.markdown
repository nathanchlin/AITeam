# Hello World 项目

这是一个简单的HTML网页项目，显示"Hello World"信息。

## 文件说明
- `index.html`: 主HTML文件，包含页面内容和基本结构
- `style.css`: 样式表文件，提供基本样式美化

## 如何使用
1. 下载所有文件到本地文件夹
2. 用浏览器打开index.html文件即可查看效果

## 浏览器兼容性
- Chrome (推荐)
- Firefox
- Safari
- Edge

## 部署选项
可以将此项目部署到任何静态网站托管服务，如:
- GitHub Pages
- Netlify
- Vercel
- 任何支持静态文件的Web服务器

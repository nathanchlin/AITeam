        class Snake {

                this.reset();
            }
            
            reset() {
                // 初始蛇身在中间，长度为3
                const middle = Math.floor(GRID_SIZE / 2);
                this.body = [
                    {x: middle, y: middle},
                    {x: middle - 1, y: middle},
                    {x: middle - 2, y: middle}
                ];
                this.direction = 'right';
                this.grow = false;
            }

                // 更新方向
                this.direction = nextDirection;
                
                // 计算新头部位置
                const head = {...this.body[0]};

                    case 'up':
                        head.y -= 1;
                        break;
                    case 'down':
                        head.y += 1;
                        break;
                    case 'left':
                        head.x -= 1;
                        break;
                    case 'right':
                        head.x += 1;
                        break;

                    this.grow = false;

                        gameBoard[segment.y][segment.x].classList.add('snake-head');
                    } else {
                        gameBoard[segment.y][segment.x].classList.add('snake');
                    }
                });

                currentSpeed = Math.max(50, currentSpeed - SPEED_INCREMENT);

                    break;

                    if (direction !== 'left') nextDirection = 'right';
                    break;

        });

## 食物生成系统详解

在上述实现中，食物生成系统是游戏的核心部分之一。以下是食物生成系统的关键实现细节：

### 1. 食物生成器类 (FoodGenerator)

```javascript
class FoodGenerator {
    constructor() {
        this.position = {x: 0, y: 0};

```

### 2. 食物生成算法

食物生成算法的核心是确保食物不会出现在蛇的身体上：

1. **随机位置生成**：使用 `Math.random()` 生成网格内的随机坐标。
2. **重叠检测**：检查生成的位置是否与蛇身体的任何部分重叠。
3. **循环直到找到有效位置**：如果位置重叠，则重复生成过程，直到找到不重叠的位置。

这种算法确保了食物总是出现在有效位置，不会与蛇身重叠，保证了游戏的公平性。

### 3. 碰撞检测

```javascript
checkCollision(snakeHead) {
    return snakeHead.x === this.position.x && snakeHead.y === this.position.y;
}
```

当蛇的头部移动到食物所在位置时，此方法返回 `true`，触发食物被吃掉的事件。

### 4. 食物被吃掉后的处理

```javascript
if (foodGenerator.checkCollision(snake.body[0])) {
    snake.growSnake();
    score += 10;
    updateScore();
    
    // 增加速度
    currentSpeed = Math.max(50, currentSpeed - SPEED_INCREMENT);
    
    // 重新生成食物
    foodGenerator.generate(snake.body);
    
    // 重新设置游戏循环
    clearInterval(gameInterval);
    gameInterval = setInterval(gameLoop, currentSpeed);
}
```

当蛇吃到食物时：
1. 蛇的身体增长
2. 分数增加
3. 游戏速度加快（增加难度）
4. 生成新的食物
5. 重置游戏循环以适应新的速度

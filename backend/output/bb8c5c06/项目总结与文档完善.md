# 贪吃蛇游戏项目总结与文档

## 1. 项目概述

本项目旨在开发一个简单的贪吃蛇游戏，玩家可以使用方向键控制蛇的移动，吃到食物后蛇身会变长，如果蛇撞到墙壁或自己的身体则游戏结束。这个项目是学习游戏开发基础和JavaScript编程的绝佳实践。

## 2. 技术实现要点

### 2.1 游戏核心组件

- **游戏画布(Canvas)**：使用HTML5 Canvas元素作为游戏的主要显示区域
- **蛇的数据结构**：使用数组存储蛇身各部分的坐标
- **食物生成**：随机生成食物位置，确保不与蛇身重叠
- **游戏循环**：使用requestAnimationFrame实现流畅的游戏循环

// 蛇的移动逻辑
function moveSnake() {
  const head = {x: snake[0].x, y: snake[0].y};
  
  // 根据方向移动头部
  switch(direction) {
    case 'UP':
      head.y -= 1;
      break;
    case 'DOWN':
      head.y += 1;
      break;
    case 'LEFT':
      head.x -= 1;

      break;

  if (checkCollision(head)) {

## 4. 技术难点与解决方案

### 4.1 碰撞检测优化

**问题**：初始实现中，蛇头与自身碰撞检测存在延迟，导致蛇可以"穿过"自己。

**解决方案**：
```javascript
function checkCollision(head) {
  // 检查是否撞墙
  if (head.x < 0 || head.x >= gridSize || head.y < 0 || head.y >= gridSize) {
    return true;
  }
  
  // 检查是否撞到自己
  for (let i = 1; i < snake.length; i++) {
    if (head.x === snake[i].x && head.y === snake[i].y) {
      return true;
    }
  }
  
  return false;
}
```

### 4.2 游戏速度控制

**问题**：随着蛇变长，游戏速度应适当加快以保持挑战性。

**解决方案**：
```javascript
// 根据分数调整游戏速度
function getGameSpeed() {
  const baseSpeed = 100; // 基础速度(毫秒)
  const speedIncrease = Math.floor(score / 5) * 10; // 每得5分增加10毫秒
  return Math.max(50, baseSpeed - speedIncrease); // 最低速度限制为50毫秒
}
```

我来为计数器网页的按钮添加事件处理函数。以下是一个完整的HTML文件，包含了所有必要的功能和事件处理：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>简单计数器</title>
    <style>
        body {
            font-family: 'Arial', sans-serif;
            display: flex;
            justify-content: center;
            align-items: center;
            height: 100vh;
            margin: 0;
            background-color: #f5f5f5;
        }
        
        .counter-container {
            background-color: white;
            border-radius: 10px;
            box-shadow: 0 4px 8px rgba(0, 0, 0, 0.1);
            padding: 30px;
            text-align: center;
            min-width: 300px;
        }
        
        h1 {
            color: #333;
            margin-top: 0;
        }
        
        #counter {
            font-size: 48px;

            margin: 20px 0;
        }
        
        .button-container {
            display: flex;
            justify-content: space-between;
            gap: 10px;
            margin-top: 20px;
        }
        
        button {
            padding: 10px 20px;
            border: none;

            font-size: 16px;
            cursor: pointer;
            transition: background-color 0.3s;

        }
        
        #increment-btn {
            background-color: #4CAF50;

        }
        
        #increment-btn:hover {
            background-color: #45a049;
        }
        
        #decrement-btn {
            background-color: #f44336;

        }

        }
        
        #reset-btn {
            background-color: #2196F3;
            color: white;
        }
        
        #reset-btn:hover {
            background-color: #0b7dda;
        }
        
        .message {
            margin-top: 15px;
            font-size: 14px;

        }
    </style>
</head>
<body>
    <div class="counter-container">
        <h1>简单计数器</h1>
        <div id="counter">0</div>
        <div class="button-container">
            <button id="decrement-btn">减</button>
            <button id="increment-btn">加</button>
            <button id="reset-btn">重置</button>
        </div>
        <div id="message" class="message"></div>
    </div>

    <script>
        // 获取DOM元素
        const counterElement = document.getElementById('counter');
        const incrementBtn = document.getElementById('increment-btn');
        const decrementBtn = document.getElementById('decrement-btn');
        const resetBtn = document.getElementById('reset-btn');
        const messageElement = document.getElementById('message');
        
        // 初始化计数器值
        let count = 0;
        
        // 更新计数器显示
        function updateCounter() {
            counterElement.textContent = count;
            
            // 如果计数器为0，显示提示信息
            if (count === 0) {
                showMessage('计数器已归零');
            } else {
                showMessage('');
            }
        }
        
        // 显示消息
        function showMessage(message) {
            messageElement.textContent = message;
        }
        
        // 增加计数
        function increment() {
            count++;
            updateCounter();
        }
        
        // 减少计数
        function decrement() {
            if (count > 0) {
                count--;
                updateCounter();
            } else {
                showMessage('计数器不能小于0');
            }
        }
        
        // 重置计数器
        function reset() {
            count = 0;
            updateCounter();
        }
        
        // 添加事件监听器
        incrementBtn.addEventListener('click', increment);
        decrementBtn.addEventListener('click', decrement);
        resetBtn.addEventListener('click', reset);
        
        // 初始化显示
        updateCounter();
    </script>
</body>
</html>
```

### 事件处理函数说明：

1. **increment 函数**：
   - 当点击"加"按钮时触发
   - 将计数器值增加1
   - 更新显示

2. **decrement 函数**：
   - 当点击"减"按钮时触发
   - 检查计数器值是否大于0
   - 如果大于0，则减少1并更新显示
   - 如果已经为0，则显示"计数器不能小于0"的消息

3. **reset 函数**：
   - 当点击"重置"按钮时触发
   - 将计数器值重置为0
   - 更新显示

4. **辅助函数**：
   - `updateCounter()`: 更新计数器显示，并在值为0时显示提示信息
   - `showMessage()`: 显示临时消息给用户

这个实现满足了所有需求：显示数字、加减按钮、重置按钮，并确保数字不会小于0。同时，我还添加了一些用户友好的功能，如按钮悬停效果和消息提示，使界面更加直观和易用。

# 俄罗斯方块游戏

## 游戏简介
这是一个经典的俄罗斯方块游戏，使用方向键控制方块的移动和旋转，消除满行得分，当方块堆到顶部时游戏结束。

## 如何访问游戏
直接在浏览器中打开index.html文件，或者访问部署后的URL。

## 游戏控制
- **←/→**: 左右移动方块
- **↑**: 旋转方块
- **↓**: 加速方块下落
- **空格键**: 直接落到底部
- **P**: 暂停/继续游戏
- **R**: 重新开始游戏

## 游戏规则
1. 方块从顶部不断下落
2. 玩家可以控制方块的移动和旋转
3. 当一行被完全填满时，该行会被消除并得分
4. 当方块堆到顶部时，游戏结束
5. 每消除一定行数，游戏速度会增加

## 得分规则
- 消除1行: 100分
- 消除2行: 300分
- 消除3行: 500分
- 消除4行: 800分

## 保存最高分
游戏会自动保存您的最高分到浏览器本地存储，下次打开时可以看到历史最高分。

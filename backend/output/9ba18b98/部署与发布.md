# 游戏部署与发布方案

## 1. 部署准备

### 1.1 文件结构
```
tetris-game/
├── index.html          # 游戏主页面
├── css/
│   └── style.css      # 样式文件
├── js/
│   ├── game.js        # 游戏逻辑
│   └── controls.js    # 控制逻辑
├── assets/
│   └── tetris.png     # 游戏图标(可选)
└── README.md          # 使用说明文档
```

### 1.2 技术要求
- 确保服务器支持HTML5、CSS3和JavaScript
- 检查服务器是否支持本地存储(用于保存最高分)
- 确保服务器支持键盘事件监听

## 2. 部署步骤

### 2.1 选择部署平台
1. **静态网站托管服务**:
   - GitHub Pages (免费)
   - Netlify (免费)
   - Vercel (免费)
   - AWS S3 + CloudFront (付费)

2. **自托管服务器**:
   - Nginx
   - Apache
   - IIS (Windows服务器)

### 2.2 GitHub Pages 部署示例
1. 创建GitHub仓库并上传游戏文件
2. 在仓库设置中启用GitHub Pages
3. 选择主分支作为源
4. 访问生成的URL

### 2.3 Netlify 部署示例
1. 将游戏文件上传到Netlify
2. 拖拽文件夹到部署区域
3. 配置构建设置(如果是静态网站，无需构建)
4. 部署完成后获取URL

## 3. 使用说明文档 (README.md)

```markdown
# 俄罗斯方块游戏

## 游戏简介
这是一个经典的俄罗斯方块游戏，使用方向键控制方块的移动和旋转，消除满行得分，当方块堆到顶部时游戏结束。

## 如何访问游戏
直接在浏览器中打开index.html文件，或者访问部署后的URL。

## 游戏控制
- **←/→**: 左右移动方块
- **↑**: 旋转方块
- **↓**: 加速方块下落
- **空格键**: 直接落到底部
- **P**: 暂停/继续游戏
- **R**: 重新开始游戏

## 游戏规则
1. 方块从顶部不断下落
2. 玩家可以控制方块的移动和旋转
3. 当一行被完全填满时，该行会被消除并得分
4. 当方块堆到顶部时，游戏结束
5. 每消除一定行数，游戏速度会增加

## 得分规则
- 消除1行: 100分
- 消除2行: 300分
- 消除3行: 500分
- 消除4行: 800分

## 保存最高分
游戏会自动保存您的最高分到浏览器本地存储，下次打开时可以看到历史最高分。

## 技术支持
如有问题或建议，请联系开发者。
```

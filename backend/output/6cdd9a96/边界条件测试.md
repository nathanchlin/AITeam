# 边界条件测试方案

## 测试目标
验证网格边缘宝石交换和消除的特殊情况，确保游戏在各种边界条件下的正确性和稳定性。

## 边界条件分析

### 1. 网格边缘交换测试
- **左边缘交换**：测试最左侧列与相邻列的宝石交换
- **右边缘交换**：测试最右侧列与相邻列的宝石交换
- **上边缘交换**：测试最上行与相邻行的宝石交换
- **下边缘交换**：测试最下行与相邻行的宝石交换

### 2. 边缘消除测试
- **左边缘消除**：测试最左侧列的三个或更多相同宝石消除
- **右边缘消除**：测试最右侧列的三个或更多相同宝石消除
- **上边缘消除**：测试最上行的三个或更多相同宝石消除
- **下边缘消除**：测试最下行的三个或更多相同宝石消除

### 3. 角落特殊情况测试
- **左上角交换**：测试左上角宝石与右侧或下方宝石的交换
- **右上角交换**：测试右上角宝石与左侧或下方宝石的交换
- **左下角交换**：测试左下角宝石与右侧或上方宝石的交换
- **右下角交换**：测试右下角宝石与左侧或上方宝石的交换

### 4. 边缘连续消除测试
- **边缘连锁反应**：测试边缘消除引发的连续下落和消除
- **边缘多列同时消除**：测试边缘多列同时消除的情况

**问题描述:** 在Safari中，宝石下落动画出现卡顿
**浏览器:** Safari
**严重程度:** 中等
**解决方案:**
```css
/* 原始代码 */

  transition: transform 0.3s ease;
}

  transition: transform 0.3s ease-in-out;
  -webkit-transition: transform 0.3s ease-in-out;
  will-change: transform;
}
```

### 问题2: 触摸事件处理
**问题描述:** 在移动设备上，宝石交换有时不响应
**浏览器:** Safari (移动版), Chrome (移动版)
**严重程度:** 高
**解决方案:**
```javascript
// 原始代码
gem.addEventListener('click', handleGemClick);

// 修改后
gem.addEventListener('click', handleGemClick);
gem.addEventListener('touchstart', handleGemTouch);
gem.addEventListener('touchend', handleGemTouchEnd);

function handleGemTouch(e) {
  e.preventDefault();
  // 触摸处理逻辑
}
```

### 问题3: 渲染一致性
**问题描述:** 在Firefox中，宝石边缘渲染模糊
**浏览器:** Firefox
**严重程度:** 低
**解决方案:**
```css
/* 原始代码 */
.gem {
  border-radius: 8px;
}

/* 修改后 */
.gem {
  border-radius: 8px;
  -moz-transform: translateZ(0);
  transform: translateZ(0);
  backface-visibility: hidden;
}
```

### 问题4: 内存泄漏
**问题描述:** 在长时间游戏后，Chrome内存使用持续增长
**浏览器:** Chrome
**严重程度:** 中等
**解决方案:**
```javascript
// 添加事件清理
function cleanupGame() {
  gems.forEach(gem => {
    gem.removeEventListener('click', handleGemClick);
    gem.removeEventListener('touchstart', handleGemTouch);
  });
  // 其他清理工作
}

// 在页面卸载时调用

```

                // 检查水平方向

                for (let c = col - 1; c >= 0 && board[row][c] === type; c--) {

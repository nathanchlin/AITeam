# 本地多人功能实现

**Time**: 2026-02-24T22:00:05.738498

为了实现本地多人游戏模式，我们需要对之前的点击计数器游戏进行一些修改。以下是整合了本地多人功能实现的游戏代码：

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Local Multiplayer Click Counter Game</title>
<style>
  body {
    margin: 0;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    background-color: #f0f0f0;
  }
  canvas {
    border: 1px solid #000;
  }
  #player1, #player2 {
    position: absolute;
    width: 100px;
    height: 100px;
    background-color: red;
    border-radius: 50%;
    cursor: pointer;
  }
  #player2 {
    background-color: blue;
  }
</style>
</head>
<body>
<canvas id="gameCanvas" width="400" height="400"></canvas>
<div id="player1" style="left: 50px; top: 50px;"></div>
<div id="player2" style="left: 350px; top: 350px;"></div>
<script>
  const canvas = document.getElementById('gameCanvas');
  const ctx = canvas.getContext('2d');
  let player1Count = 0;
  let player2Count = 0;
  let isGameActive = false;
  let animationFrameId = null;

  function init() {
    canvas.width = 400;
    canvas.height = 400;
    ctx.font = '24px Arial';
    ctx.fillStyle = 'black';
    ctx.fillText('Player 1: 0', 50, 50);
    ctx.fillText('Player 2: 0', 250, 50);
    document.getElementById('player1').addEventListener('click', handlePlayer1Click);
    document.getElementById('player2').addEventListener('click', handlePlayer2Click);
    window.addEventListener('resize', resizeCanvas);
    resizeCanvas();
  }

  function resizeCanvas() {
    canvas.width = window.innerWidth * 0.8;
    canvas.height = window.innerHeight * 0.8;
    ctx.font = (canvas.height * 0.05) + 'px Arial';
  }

  function handlePlayer1Click() {
    player1Count++;
    updateCounts();
  }

  function handlePlayer2Click() {
    player2Count++;
    updateCounts();
  }

  function updateCounts() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.fillText('Player 1: ' + player1Count, 50, 50);
    ctx.fillText('Player 2: ' + player2Count, 250, 50);
  }

  window.onload = init;
</script>
</body>
</html>
```

这段代码实现了以下功能：

1. 使用了 `<canvas>` 元素来显示点击计数。
2. 添加了两个 `<div>` 元素作为玩家的控制区域，玩家可以通过点击这些区域来增加自己的计数。
3. 通过 `handlePlayer1Click` 和 `handlePlayer2Click` 函数来处理玩家的点击事件，并更新计数。
4. 使用 `updateCounts` 函数来在画布上更新玩家的计数。
5. 通过 `resizeCanvas` 函数来确保游戏界面在窗口大小改变时能够适应。

请注意，这个示例中我们使用了绝对定位的 `<div>` 元素来模拟玩家的控制区域，实际的游戏中可能需要更复杂的逻辑来处理玩家的移动和交互。此外，这个示例没有实现轮流或分屏的功能，因为这通常需要更复杂的游戏逻辑和状态管理。

# 游戏界面与基础渲染

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Click Counter Game</title>
<style>
  body {
    margin: 0;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    background-color: #f0f0f0;
  }
  canvas {
    border: 1px solid #000;
  }
</style>
</head>
<body>
<canvas id="gameCanvas" width="400" height="400"></canvas>
<script>
  const canvas = document.getElementById('gameCanvas');
  const ctx = canvas.getContext('2d');
  let count = 0;

  function init() {
    canvas.width = 400;
    canvas.height = 400;
    ctx.font = '24px Arial';
    ctx.fillStyle = 'black';
    ctx.fillText('Click to start!', canvas.width / 2 - 100, canvas.height / 2 - 30);
    canvas.addEventListener('click', handleClick);
  }

  function handleClick(event) {
    if (count === 0) {
      requestAnimationFrame(gameLoop);
    }
    const rect = canvas.getBoundingClientRect();
    const x = event.clientX - rect.left;
    const y = event.clientY - rect.top;
    if (x > 50 && x < 350 && y > 50 && y < 350) {
      count++;
      ctx.clearRect(0, 0, canvas.width, canvas.height);
      ctx.fillText('Click count: ' + count, 50, 50);
    }
  }

  function gameLoop() {
    ctx.fillStyle = 'rgba(0, 0, 0, 0.05)';
    ctx.fillRect(0, 0, canvas.width, canvas.height);
    ctx.fillText('Click count: ' + count, 50, 50);
    requestAnimationFrame(gameLoop);
  }

  window.onload = init;
</script>
</body>
</html>
```

这段代码定义了一个简单的点击计数器游戏，满足以下要求：

- 使用了 `<canvas>` 元素。
- 通过 `getContext('2d')` 获取了 2D 上下文。
- 使用了 `requestAnimationFrame` 实现了游戏循环。
- 使用了 `window.onload` 来初始化游戏。
- 绑定了鼠标点击事件。
- 游戏界面中有一个计数显示，点击区域在画布的中央区域。
- HTML 文件是一个单文件，包含内联 CSS 和 JavaScript，无需外部文件即可运行。

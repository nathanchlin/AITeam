## 6. 模块间交互

### 6.1 事件流

1. **游戏循环启动**：`GameLogic` 初始化游戏状态
2. **输入处理**：`Controller` 捕获用户输入并更新方向
3. **状态更新**：`GameLogic` 根据当前方向更新蛇的位置
4. **碰撞检测**：`GameLogic` 检查蛇是否撞墙或自身
5. **计分更新**：`ScoreSystem` 在蛇吃到食物时更新分数
6. **渲染请求**：`Renderer` 根据游戏状态渲染画面

### 6.2 数据流向

```
Controller → GameLogic (方向输入)
GameLogic → Renderer (游戏状态数据)
GameLogic → ScoreSystem (分数更新)
GameLogic → Controller (游戏状态变化通知)
```

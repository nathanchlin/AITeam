## 3. 开发服务器搭建

### 本地开发环境
1. **前端服务器**：使用Webpack Dev Server，支持热重载
2. **后端服务器**：使用Express + Socket.io，处理游戏逻辑和实时通信
3. **代理配置**：前端开发服务器通过代理访问后端API

```javascript
// webpack.config.js 示例
const path = require('path');

module.exports = {
  entry: './src/client/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
  },
  devServer: {
    proxy: {
      '/api': 'http://localhost:3000',
      '/socket.io': {
        target: 'http://localhost:3000',
        ws: true
      }
    }
  }
};
```

### 生产环境部署
1. **前端**：Nginx托管静态文件
2. **后端**：使用PM2集群模式运行
3. **数据库**：根据需求选择MongoDB或PostgreSQL

```javascript
// ecosystem.config.js (PM2配置)
module.exports = {
  apps: [{
    name: 'tetris-battle-server',
    script: 'index.js',
    instances: 'max',
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'production'
    }
  }]
};
```

## 4. 团队协作流程定义

### 开发流程
1. **需求分析**：创建GitHub Issue描述功能需求
2. **分支创建**：从`develop`创建`feature/*`分支
3. **开发**：实现功能，编写测试
4. **代码审查**：通过Pull Request进行代码审查
5. **合并**：审查通过后合并到`develop`分支
6. **发布**：定期从`develop`创建发布版本

### 代码规范
- **JavaScript Standard Style**：统一代码风格
- **ESLint规则**：强制执行代码质量标准
- **提交规范**：使用Conventional Commits格式

```bash
# 提交消息示例
feat: 添加AI难度选择功能
fix: 修复方块旋转碰撞检测问题
docs: 更新游戏规则文档
```

### 持续集成/持续部署(CI/CD)
1. **GitHub Actions**配置自动化测试和构建
2. **测试覆盖率**：确保单元测试覆盖率不低于80%
3. **自动化部署**：通过GitHub Actions自动部署到测试环境

```yaml
# .github/workflows/ci.yml 示例
name: CI/CD Pipeline
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '14'
      - run: npm install
      - run: npm test
  deploy:
    if: github.ref == 'refs/heads/main'
    needs: test
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to production
        run: echo "Deploying to production..."
```

### 文档维护
1. **API文档**：使用Swagger自动生成
2. **代码注释**：关键函数和复杂逻辑必须有注释
3. **README更新**：定期更新项目说明文档

## 7. 开发环境启动流程

1. 克隆仓库：`git clone <repository-url>`
2. 安装依赖：`npm install`
3. 启动后端：`npm run dev` (端口3000)
4. 启动前端：`npm start` (端口8080)
5. 访问应用：`http://localhost:8080`

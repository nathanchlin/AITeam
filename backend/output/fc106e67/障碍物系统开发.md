# 障碍物系统开发方案

## 系统概述

为《忍者必须死》跑酷游戏设计一个灵活、可扩展的障碍物系统，支持多种障碍物类型和随机生成机制。

## 障碍物类型设计

### 1. 静态障碍物
- **尖刺陷阱**：造成即时伤害
- **墙壁**：需要跳跃或滑铲躲避
- **深坑**：导致游戏失败

### 2. 动态障碍物
- **移动平台**：上下或左右移动
- **旋转刀片**：旋转的障碍物
- **发射物**：如箭矢、飞镖等

### 3. 环境障碍物
- **落石**：从上方掉落
- **障碍组合**：多个障碍物的组合

### 3. 难度递增系统

```python
class DifficultyManager:
    def __init__(self):
        self.score_thresholds = [100, 300, 600, 1000, 1500]
        self.current_level = 1
        
    def update_level(self, score):
        """根据分数更新难度等级"""
        for i, threshold in enumerate(self.score_thresholds):
            if score >= threshold:
                self.current_level = i + 1
            else:
                break
                
    def get_obstacle_speed(self, base_speed):
        """根据难度获取障碍物速度"""
        return base_speed * (1 + 0.2 * (self.current_level - 1))
        
    def get_spawn_interval(self, base_interval):
        """根据难度获取生成间隔"""
        return max(500, base_interval - 50 * (self.current_level - 1))
```

## 障碍物管理器

```python
class ObstacleManager:
    def __init__(self, game_width, game_height):
        self.obstacles = []
        self.generator = ObstacleGenerator(game_width, game_height)
        self.difficulty_manager = DifficultyManager()
        self.game_speed = 5
        
    def update(self, delta_time, score):
        """更新所有障碍物"""
        # 更新难度
        self.difficulty_manager.update_level(score)
        
        # 更新生成器
        self.generator.spawn_interval = self.difficulty_manager.get_spawn_interval(self.generator.spawn_interval)
        self.generator.update(delta_time, self.game_speed)
        
        # 更新游戏速度
        self.game_speed = self.difficulty_manager.get_obstacle_speed(self.game_speed)
        
        # 更新所有障碍物
        for obstacle in self.obstacles[:]:
            obstacle.update(self.game_speed)
            
            # 移除屏幕外的障碍物
            if obstacle.x + obstacle.width < 0:
                self.obstacles.remove(obstacle)
                
    def add_obstacle(self, obstacle):
        """添加新障碍物"""
        self.obstacles.append(obstacle)
        
    def check_collisions(self, player):
        """检查所有障碍物与玩家的碰撞"""
        for obstacle in self.obstacles:
            if obstacle.check_collision(player):
                return obstacle
        return None
        
    def draw(self, screen):
        """绘制所有障碍物"""
        for obstacle in self.obstacles:
            obstacle.draw(screen)
```

## 使用示例

```python
# 游戏主循环中
obstacle_manager = ObstacleManager(game_width, game_height)

def game_loop():
    clock = pygame.time.Clock()
    running = True
    score = 0
    delta_time = 0
    
    while running:
        # 处理事件
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
                
        # 更新游戏状态
        player.update(delta_time)
        obstacle_manager.update(delta_time, score)
        
        # 检查碰撞
        hit_obstacle = obstacle_manager.check_collisions(player)
        if hit_obstacle:
            player.take_damage(hit_obstacle.damage)
            
        # 绘制
        screen.fill((135, 206, 235))  # 天蓝色背景
        player.draw(screen)
        obstacle_manager.draw(screen)
        
        # 更新分数
        score += 1
        
        pygame.display.flip()
        delta_time = clock.tick(60)
```

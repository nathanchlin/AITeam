# 绿色忍者角色创建方案

我将为"忍者必须死的跑酷游戏"设计一个绿色忍者角色模型，包含外观渲染和基础动画系统。

## 角色设计概述

绿色忍者将作为游戏的主角，具有敏捷、灵活的特点，符合跑酷游戏的玩法需求。角色设计将包含以下核心要素：

1. 外观模型：绿色主题的忍者造型
2. 材质系统：具有金属质感的服装材质
3. 骨骼结构：适合跑酷动作的骨骼布局
4. 动画系统：基础移动、跳跃、滑铲等动作

public class NinjaAnimatorController : MonoBehaviour
{
    private Animator animator;
    private int isRunningHash = Animator.StringToHash("IsRunning");
    private int isJumpingHash = Animator.StringToHash("IsJumping");

    {
        animator = GetComponent<Animator>();

        animator.SetBool(isRunningHash, isRunning);
    }

        animator.SetBool(isJumpingHash, isJumping);

### 4. 角色控制系统

```csharp
public class NinjaController : MonoBehaviour
{
    private NinjaCharacter ninja;
    private NinjaAnimatorController animatorController;
    
    void Start()
    {
        ninja = GetComponent<NinjaCharacter>();
        animatorController = GetComponent<NinjaAnimatorController>();
    }
    
    void Update()
    {
        HandleMovement();
        HandleJump();
        HandleSlide();
    }
    
    private void HandleMovement()
    {
        // 前进移动（跑酷游戏自动前进）
        animatorController.SetRunning(true);
    }
    
    private void HandleJump()
    {
        if (Input.GetButtonDown("Jump") && ninja.IsGrounded())
        {
            ninja.Jump();
            animatorController.SetJumping(true);
        }
    }
    
    private void HandleSlide()
    {
        if (Input.GetButtonDown("Fire1") && !ninja.IsSliding() && ninja.IsGrounded())
        {
            ninja.StartSlide();
            animatorController.SetSliding(true);
        }
    }
}
```

## 动画状态机设计

使用Unity的Animator工具创建以下动画状态：

1. **Idle** - 站立状态
2. **Run** - 跑步状态（默认状态）
3. **Jump** - 跳跃状态
4. **Slide** - 滑铲状态
5. **Land** - 落地状态

状态转换逻辑：
- Run → Jump: 当跳跃输入触发
- Jump → Land: 当角色落地时
- Run → Slide: 当滑铲输入触发
- Slide → Run: 滑铲结束后

## 性能优化

1. **LOD (Level of Detail)**：为角色模型创建不同细节等级
2. **动画骨骼优化**：减少不必要的骨骼数量
3. **材质合批**：使用共享材质减少绘制调用
4. **动画状态优化**：使用动画层和混合树减少状态转换开销

# 角色控制系统开发方案

我将为您开发一个完整的角色控制系统，支持左右移动、跳跃等功能，并包含角色动画和物理属性。这个系统将适用于"男人下100层"游戏类型。

## 系统设计概述

角色控制系统将包含以下核心功能：
- 角色移动控制（左右移动）
- 跳跃机制
- 基本物理属性（重力、速度等）
- 角色动画状态管理
- 碰撞检测

## 实现代码

以下是使用Unity C#的实现方案：

```csharp
using UnityEngine;

public class CharacterController : MonoBehaviour
{
    [Header("Movement Settings")]
    [SerializeField] private float moveSpeed = 5f;
    [SerializeField] private float jumpForce = 10f;
    [SerializeField] private float groundCheckDistance = 0.1f;
    
    [Header("Physics Settings")]
    [SerializeField] private LayerMask groundLayer;
    [SerializeField] private Rigidbody2D rb;
    
    [Header("Animation Settings")]
    [SerializeField] private Animator animator;
    [SerializeField] private string moveAnimationParam = "Speed";
    [SerializeField] private string jumpAnimationParam = "IsJumping";
    
    private bool isGrounded;
    private bool facingRight = true;
    private float horizontalInput;
    
    // 初始化
    private void Awake()
    {
        if (rb == null) rb = GetComponent<Rigidbody2D>();
        if (animator == null) animator = GetComponent<Animator>();
    }
    
    private void Update()
    {
        // 获取输入
        HandleInput();
        
        // 检查是否在地面上
        CheckGrounded();
        
        // 处理动画
        HandleAnimation();
    }
    
    private void FixedUpdate()
    {
        // 处理物理移动
        HandleMovement();
    }
    
    private void HandleInput()
    {
        // 获取水平输入
        horizontalInput = Input.GetAxisRaw("Horizontal");
        
        // 跳跃输入
        if (Input.GetButtonDown("Jump") && isGrounded)
        {
            Jump();
        }
    }
    
    private void HandleMovement()
    {
        // 设置水平速度
        Vector2 velocity = rb.velocity;
        velocity.x = horizontalInput * moveSpeed;
        rb.velocity = velocity;
        
        // 处理角色朝向
        if (horizontalInput > 0 && !facingRight)
        {
            Flip();
        }
        else if (horizontalInput < 0 && facingRight)
        {
            Flip();
        }
    }
    
    private void Jump()
    {
        // 添加向上的力
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    }
    
    private void Flip()
    {
        // 反转角色朝向
        facingRight = !facingRight;
        Vector3 scale = transform.localScale;
        scale.x *= -1;
        transform.localScale = scale;
    }
    
    private void CheckGrounded()
    {
        // 使用射线检测是否在地面上
        isGrounded = Physics2D.Raycast(transform.position, Vector2.down, groundCheckDistance, groundLayer);
    }
    
    private void HandleAnimation()
    {
        // 更新移动动画参数
        animator.SetFloat(moveAnimationParam, Mathf.Abs(horizontalInput));
        
        // 更新跳跃动画参数
        animator.SetBool(jumpAnimationParam, !isGrounded);
    }
    
    // 可选：添加地面检测的可视化调试
    private void OnDrawGizmosSelected()
    {
        Gizmos.color = isGrounded ? Color.green : Color.red;
        Gizmos.DrawLine(transform.position, transform.position + Vector3.down * groundCheckDistance);
    }
}
```

## 动画控制器设置

建议创建一个简单的动画控制器，包含以下状态：
1. 空闲状态
2. 移动状态
3. 跳跃状态

动画参数：
- Speed: 控制移动速度的浮点数
- IsJumping: 控制是否跳跃的布尔值

## 物理属性配置

1. **重力设置**：
   - 在Rigidbody2D组件中设置适当的重力值（通常9.8）

2. **碰撞体设置**：
   - 为角色添加BoxCollider2D或CapsuleCollider2D
   - 设置适当的Is Trigger属性（根据游戏需求）

3. **地面层设置**：
   - 创建一个"Ground"层
   - 将地面对象分配到此层
   - 在角色控制器中设置groundLayer为"Ground"

## 扩展功能

### 1. 添加双跳能力

```csharp
private int jumpCount = 0;
[SerializeField] private int maxJumps = 2;

private void Jump()
{
    if (jumpCount < maxJumps)
    {
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
        jumpCount++;
    }
}

private void OnCollisionEnter2D(Collision2D collision)
{
    if (collision.gameObject.layer == groundLayer)
    {
        jumpCount = 0;
    }
}
```

### 2. 添加滑行功能

```csharp
[SerializeField] private float slideSpeed = 8f;
[SerializeField] private KeyCode slideKey = KeyCode.LeftControl;
private bool isSliding = false;

private void Update()
{
    // 滑行输入
    if (Input.GetKeyDown(slideKey) && isGrounded)
    {
        isSliding = true;
    }
    else if (Input.GetKeyUp(slideKey))
    {
        isSliding = false;
    }
}

private void HandleMovement()
{
    float currentSpeed = isSliding ? slideSpeed : moveSpeed;
    Vector2 velocity = rb.velocity;
    velocity.x = horizontalInput * currentSpeed;
    rb.velocity = velocity;
}
```

### 3. 添加攻击功能

```csharp
[SerializeField] private KeyCode attackKey = KeyCode.Space;
[SerializeField] private float attackRange = 0.5f;
[SerializeField] private LayerMask enemyLayer;

private void Update()
{
    // 攻击输入
    if (Input.GetKeyDown(attackKey))
    {
        Attack();
    }
}

private void Attack()
{
    // 检测范围内的敌人
    Collider2D[] hitEnemies = Physics2D.OverlapCircleAll(transform.position, attackRange, enemyLayer);
    
    foreach (var enemy in hitEnemies)
    {
        // 对敌人造成伤害
        enemy.GetComponent<EnemyHealth>()?.TakeDamage(1);
    }
}
```

2. **状态机**：对于更复杂的行为，考虑使用有限状态机或行为树
3. **输入系统**：考虑使用Unity的新输入系统以获得更好的跨平台支持
4. **参数化**：将更多参数暴露到Inspector中，便于调整

# 坦克大战游戏文档与部署方案

## 一、游戏说明文档

### 1. 游戏概述
坦克大战是一款双人对战网页游戏，玩家控制己方坦克保护总部，同时攻击对方总部以获得胜利。

### 2. 游戏规则
- 游戏目标：摧毁对方总部或消灭对方所有坦克
- 玩家控制：使用键盘方向键控制坦克移动，空格键发射子弹
- 胜利条件：摧毁对方总部或消灭对方所有坦克
- 失败条件：己方总部被摧毁或己方所有坦克被消灭

### 3. 操作说明
- **方向键**：控制坦克移动（上、下、左、右）
- **空格键**：发射子弹
- **P键**：暂停/继续游戏

### 4. 游戏元素
- **坦克**：玩家控制单位，有生命值和攻击力
- **总部**：需要保护的目标，被摧毁则游戏失败
- **子弹**：攻击武器，击中坦克会造成伤害
- **障碍物**：地图上的障碍，可阻挡子弹和坦克移动

### 5. 技术要求
- 支持浏览器：Chrome 60+、Firefox 55+、Safari 11+、Edge 79+
- 网络要求：单机游戏，无需网络连接
- 分辨率适配：自适应主流屏幕分辨率

### 2. 部署步骤

#### 2.1 本地部署
1. 将所有文件放入本地Web服务器目录（如Apache、Nginx）
2. 启动本地服务器
3. 在浏览器中访问 `http://localhost/tank-battle/`

#### 2.2 静态托管服务部署
1. 注册静态托管服务（如GitHub Pages、Netlify、Vercel）
2. 将项目代码上传至Git仓库
3. 配置托管服务自动部署

#### 2.3 服务器部署（Nginx示例）
```nginx
server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/tank-battle;
    
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # 缓存静态资源
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, no-transform";
    }
}
```

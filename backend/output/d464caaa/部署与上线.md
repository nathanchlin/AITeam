# 俄罗斯方块对战游戏部署与上线方案

## 部署架构设计

### 1. 服务器架构
- **前端**: 静态资源托管在CDN，减少服务器负载
- **后端**: 采用微服务架构，分离游戏逻辑、用户认证、排行榜等功能
- **数据库**: 
  - 主数据库: PostgreSQL (存储用户数据、游戏记录)
  - 缓存层: Redis (缓存游戏状态、用户会话)
- **AI服务**: 独立部署，提供AI对战能力

### 2. 可扩展性设计
- **容器化**: 使用Docker封装各服务
- **编排**: Kubernetes进行容器编排，实现自动扩缩容
- **负载均衡**: Nginx作为反向代理，实现负载均衡

## 部署步骤

### 1. 环境准备
```bash
# 安装必要组件
sudo apt update
sudo apt install -y docker.io docker-compose kubectl nginx

# 配置防火墙
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

### 2. 应用容器化
```dockerfile
# Dockerfile - 后端服务
FROM node:16-alpine

WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production

COPY . .
EXPOSE 3000

CMD ["npm", "start"]
```

```dockerfile
# Dockerfile - AI服务
FROM python:3.9-slim

WORKDIR /app
COPY requirements.txt ./
RUN pip install -r requirements.txt

COPY . .
EXPOSE 5000

CMD ["python", "ai_server.py"]
```

### 3. Kubernetes部署配置
```yaml
# backend-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: tetris-backend
spec:
  replicas: 3
  selector:
    matchLabels:
      app: tetris-backend
  template:
    metadata:
      labels:
        app: tetris-backend
    spec:
      containers:
      - name: backend
        image: your-registry/tetris-backend:latest
        ports:
        - containerPort: 3000
        resources:
          requests:
            memory: "256Mi"
            cpu: "250m"
          limits:
            memory: "512Mi"
            cpu: "500m"
        env:
        - name: DB_HOST
          value: "postgres-service"
        - name: REDIS_HOST
          value: "redis-service"
```

```yaml
# ai-service-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: tetris-ai
spec:
  replicas: 2
  selector:
    matchLabels:
      app: tetris-ai
  template:
    metadata:
      labels:
        app: tetris-ai
    spec:
      containers:
      - name: ai-service
        image: your-registry/tetris-ai:latest
        ports:
        - containerPort: 5000
        resources:
          requests:
            memory: "512Mi"
            cpu: "500m"
          limits:
            memory: "1Gi"
            cpu: "1000m"
```

### 4. CI/CD管道配置
```yaml
# .github/workflows/deploy.yml
name: Deploy to Production

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    
    - name: Build Docker images
      run: |
        docker build -t your-registry/tetris-backend:${{ github.sha }} -f backend/Dockerfile .
        docker build -t your-registry/tetris-ai:${{ github.sha }} -f ai/Dockerfile .
        docker push your-registry/tetris-backend:${{ github.sha }}
        docker push your-registry/tetris-ai:${{ github.sha }}
    
    - name: Deploy to Kubernetes
      run: |
        kubectl set image deployment/tetris-backend backend=your-registry/tetris-backend:${{ github.sha }}
        kubectl set image deployment/tetris-ai ai-service=your-registry/tetris-ai:${{ github.sha }}
```

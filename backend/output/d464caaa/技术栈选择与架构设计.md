# 技术栈选择与架构设计：俄罗斯方块对战游戏

## 技术栈选择

基于需求分析，我选择 **JavaScript + HTML5 Canvas** 作为技术栈，理由如下：

1. **跨平台性**：Web应用可以在任何现代浏览器中运行，无需安装额外软件
2. **原生Canvas API**：完全满足要求，不依赖外部游戏框架
3. **实时对战潜力**：JavaScript便于实现网络通信功能（虽然当前需求为AI对战，但未来可扩展为真人对战）
4. **单文件实现**：便于创建一个完整的HTML文件，包含所有游戏逻辑

## 系统架构设计

### 整体架构

```
俄罗斯方块对战游戏
├── 游戏引擎 (Game Engine)
│   ├── 游戏循环 (Game Loop)
│   ├── 渲染系统 (Renderer)
│   └── 输入处理 (Input Handler)
├── 游戏逻辑 (Game Logic)
│   ├── 方块系统 (Block System)
│   ├── 游戏板 (Game Board)
│   ├── 碰撞检测 (Collision Detection)
│   └── 得分系统 (Scoring System)
├── AI系统 (AI System)
│   ├── AI决策 (AI Decision)
│   └── 预测系统 (Prediction)
└── UI系统 (UI System)
    ├── 游戏界面 (Game Interface)
    └── 菜单系统 (Menu System)
```

### 模块划分

1. **游戏引擎模块**：负责游戏循环、渲染和输入处理
2. **游戏逻辑模块**：处理俄罗斯方块的核心游戏机制
3. **AI系统模块**：实现AI对手的决策逻辑
4. **UI系统模块**：处理游戏界面和菜单

        // 方块类
        class Piece {
            constructor(shape, color) {
                this.shape = shape;
                this.color = color;
                this.x = Math.floor((COLS - shape[0].length) / 2);
                this.y = 0;
            }
            
            rotate() {
                const rotated = [];
                const rows = this.shape.length;
                const cols = this.shape[0].length;
                
                for (let i = 0; i < cols; i++) {
                    rotated[i] = [];
                    for (let j = rows - 1; j >= 0; j--) {
                        rotated[i][rows - 1 - j] = this.shape[j][i];
                    }
                }
                
                return rotated;
            }

        // 检查碰撞
        function checkCollision(board, piece, dx = 0, dy = 0) {
            for (let y = 0; y < piece.shape.length; y++) {
                for (let x = 0; x < piece.shape[y].length; x++) {
                    if (piece.shape[y][x]) {
                        const newX = piece.x + x + dx;
                        const newY = piece.y + y + dy;
                        
                        if (newX < 0 || newX >= COLS || newY >= ROWS) {
                            return true;
                        }
                        
                        if (newY >= 0 && board[newY][newX]) {
                            return true;
                        }
                    }
                }
            }
            return false;
        }

                        const boardX = piece.x + x;

                        }
                    }
                }
            }
        }

        // AI寻找最佳移动
        function findBestMove(board, piece) {
            let bestScore = -Infinity;
            let bestMove = null;
            
            // 尝试所有可能的x位置
            for (let x = 0; x < COLS; x++) {
                // 尝试所有可能的旋转
                for (let rotations = 0; rotations < 4; rotations++) {
                    const testPiece = new Piece(piece.shape, piece.color);
                    testPiece.x = x;
                    testPiece.y = 0;
                    
                    // 应用旋转
                    for (let r = 0; r < rotations; r++) {
                        testPiece.shape = testPiece.rotate();
                    }
                    
                    // 找到可以落下的最低位置
                    while (!checkCollision(board, testPiece, 0, 1)) {
                        testPiece.y++;
                    }
                    
                    // 计算这个位置的得分
                    const score = evaluatePosition(board, testPiece);
                    
                    if (score > bestScore) {
                        bestScore = score;
                        bestMove = {
                            x: x,
                            y: testPiece.y,
                            rotations: rotations
                        };
                    }
                }
            }
            
            return bestMove;
        }
        
        // 评估位置得分
        function evaluatePosition(board, piece) {
            // 创建临时板
            const tempBoard = board.map(row => [...row]);
            lockPiece(tempBoard, piece);
            
            // 计算得分
            let score = 0;
            
            // 1. 鼓励清除行
            const linesCleared = clearLines(tempBoard);
            score += linesCleared * 100;
            
            // 2. 惩罚高度
            const maxHeight = getMaxHeight(tempBoard);
            score -= maxHeight * 10;
            
            // 3. 惩罚空洞
            const holes = countHoles(tempBoard);
            score -= holes * 20;
            
            // 4. 鼓励平整表面
            const bumpiness = getBumpiness(tempBoard);
            score -= bumpiness * 5;
            
            return score;

# 玩家控制与移动逻辑

**Time**: 2026-02-21T22:05:27.433210

为了实现玩家控制与移动逻辑，我们需要绑定键盘和鼠标事件，并更新玩家的位置。以下是一个简单的示例，它使用原生Canvas API来处理玩家的移动。

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>修仙沙盘游戏</title>
<style>
  body {
    margin: 0;
    overflow: hidden;
  }
  canvas {
    display: block;
  }
</style>
</head>
<body>
<canvas id="gameCanvas"></canvas>
<script>
const canvas = document.getElementById('gameCanvas');
const ctx = canvas.getContext('2d');
const scale = 32;
canvas.width = 800;
canvas.height = 600;

// 玩家对象
const player = {
  x: 100,
  y: 100,
  width: 32,
  height: 32,
  speed: 5
};

// 地图数据
const map = [
  // ... 地图数据
];

// 绘制玩家
function drawPlayer() {
  ctx.fillStyle = 'blue';
  ctx.fillRect(player.x, player.y, player.width, player.height);
}

// 绘制地图
function drawMap() {
  for (let y = 0; y < canvas.height; y += scale) {
    for (let x = 0; x < canvas.width; x += scale) {
      ctx.fillStyle = 'green';
      ctx.fillRect(x, y, scale, scale);
    }
  }
}

// 更新玩家位置
function updatePlayerPosition() {
  const keys = {
    ArrowUp: { direction: 'up', step: -player.speed },
    ArrowDown: { direction: 'down', step: player.speed },
    ArrowLeft: { direction: 'left', step: -player.speed },
    ArrowRight: { direction: 'right', step: player.speed }
  };

  Object.keys(keys).forEach(key => {
    window.addEventListener(key, (e) => {
      if (keys[key].direction === 'up' && player.y > 0) {
        player.y += keys[key].step;
      } else if (keys[key].direction === 'down' && player.y < canvas.height - player.height) {
        player.y += keys[key].step;
      } else if (keys[key].direction === 'left' && player.x > 0) {
        player.x += keys[key].step;
      } else if (keys[key].direction === 'right' && player.x < canvas.width - player.width) {
        player.x += keys[key].step;
      }
    });
  });
}

// 游戏循环
function gameLoop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  drawMap();
  drawPlayer();
  requestAnimationFrame(gameLoop);
}

// 初始化游戏
window.onload = () => {
  updatePlayerPosition();
  gameLoop();
};
</script>
</body>
</html>
```

这段代码创建了一个简单的修仙沙盘游戏，玩家可以通过键盘的箭头键来控制。玩家会以一定的速度在画布上移动，并且地图上的每个单元格都会被绘制出来。

注意以下几点：
- 我们定义了一个`player`对象来存储玩家的位置和大小。
- 使用`drawPlayer`和`drawMap`函数来绘制玩家和地图。
- `updatePlayerPosition`函数用于处理键盘事件，并更新玩家的位置。
- `gameLoop`函数是游戏的主循环，它使用`requestAnimationFrame`来持续更新和重绘游戏状态。

请确保将地图数据填充到`map`数组中，以便正确渲染地图。

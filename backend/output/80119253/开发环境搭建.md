# 五子棋游戏开发环境搭建指南

很高兴能帮您搭建五子棋游戏的开发环境。以下是详细的步骤指南：

## 1. 开发环境配置

### 基础工具安装
- **代码编辑器**：推荐 Visual Studio Code (VS Code)
  - 下载地址：https://code.visualstudio.com/
  - 安装后建议扩展：
    - ESLint (代码规范检查)
    - Prettier (代码格式化)
    - GitLens (Git增强)
    - Live Server (本地服务器)

- **Node.js**：用于前端构建工具和包管理
  - 下载地址：https://nodejs.org/
  - 选择LTS版本

### 验证安装
```bash
node -v  # 检查Node.js版本
npm -v   # 检查npm版本
```

## 2. 项目初始化

### 创建项目目录
```bash
mkdir gomoku-game
cd gomoku-game
```

### 初始化npm项目
```bash
npm init -y
```

### 安装项目依赖
```bash
# 前端框架
npm install react react-dom

# 构建工具
npm install webpack webpack-cli webpack-dev-server --save-dev

# 样式处理
npm install css-loader style-loader --save-dev
npm install @emotion/react @emotion/styled --save

# 测试工具
npm install jest @testing-library/react @testing-library/jest-dom --save-dev
```

## 4. 项目结构设置

建议的项目目录结构：
```
gomoku-game/
├── src/
│   ├── components/     # 组件
│   ├── hooks/         # 自定义hooks
│   ├── utils/         # 工具函数
│   ├── styles/        # 样式文件
│   ├── assets/        # 静态资源
│   ├── App.js         # 主应用组件
│   └── index.js       # 入口文件
├── public/            # 公共资源
├── tests/             # 测试文件
├── .gitignore         # Git忽略文件
├── package.json       # 项目配置
├── webpack.config.js  # Webpack配置
└── README.md          # 项目说明
```

创建基本文件：
```bash
mkdir -p src/components src/hooks src/utils src/styles src/assets public tests
touch src/App.js src/index.js public/index.html webpack.config.js
```

## 5. 项目管理工具设置

### 添加ESLint配置
```bash
npm install eslint eslint-plugin-react eslint-plugin-react-hooks --save-dev
```

创建 `.eslintrc.json`:
```json
{
  "extends": ["eslint:recommended", "plugin:react/recommended", "plugin:react-hooks/recommended"],
  "env": {
    "browser": true,
    "node": true
  },
  "rules": {
    "react/prop-types": "off",
    "react/react-in-jsx-scope": "off"
  }
}
```

### 添加Prettier配置
创建 `.prettierrc`:
```json
{
  "singleQuote": true,
  "trailingComma": "es5",
  "tabWidth": 2,
  "semi": false,
  "printWidth": 80
}
```

### 添加测试脚本
在 `package.json` 中添加：
```json
"scripts": {
  "start": "webpack serve --mode development",
  "build": "webpack --mode production",
  "test": "jest",
  "lint": "eslint src",
  "lint:fix": "eslint src --fix"
}
```

## 6. 五子棋游戏开发建议

### 组件规划
- `Board` - 棋盘组件

4. 添加游戏重置功能
5. 实现双人对战模式
6. 添加AI对手(可选)

## 7. 开发流程建议

1. **分支策略**：使用Git Flow或GitHub Flow
   - `main` - 主分支，保持稳定
   - `develop` - 开发分支
   - `feature/*` - 功能分支

2. **提交规范**：使用Conventional Commits
   ```
   feat: 添加新功能
   fix: 修复bug
   docs: 文档更新
   style: 代码格式化
   refactor: 代码重构
   test: 测试相关
   ```

3. **定期提交**：保持小而频繁的提交
4. **代码审查**：通过Pull Request进行代码审查

添加部署脚本到 `package.json`:

安装gh-pages:

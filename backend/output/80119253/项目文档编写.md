# 五子棋游戏项目文档

## 1. 开发文档

### 1.1 项目概述
本项目旨在开发一个功能完善的五子棋游戏，支持人机对战和双人对战模式，具有友好的用户界面和完整的游戏功能。

### 1.5 核心算法
#### 1.5.1 胜负判定算法
```javascript
function checkWin(board, row, col, player) {
  // 检查四个方向：水平、垂直、对角线、反对角线
  const directions = [
    [[0, 1], [0, -1]],   // 水平
    [[1, 0], [-1, 0]],   // 垂直
    [[1, 1], [-1, -1]],  // 对角线
    [[1, -1], [-1, 1]]   // 反对角线
  ];
  
  for (const direction of directions) {
    let count = 1;
    
    for (const [dx, dy] of direction) {
      let r = row + dx;
      let c = col + dy;
      
      while (r >= 0 && r < 15 && c >= 0 && c < 15 && board[r][c] === player) {
        count++;
        r += dx;
        c += dy;
      }
    }
    
    if (count >= 5) {
      return true;
    }
  }
  
  return false;
}
```

## 2. 用户手册

### 2.1 安装与运行
1. 下载项目代码
2. 解压到本地目录
3. 用浏览器打开 `index.html` 文件
4. 无需安装其他依赖，可直接运行

### 2.2 游戏界面说明
![游戏界面](假设有图片)

1. **标题栏**：显示游戏名称和当前玩家
2. **棋盘区域**：15×15的网格，用于落子
3. **控制面板**：
   - 新游戏按钮
   - 模式选择（人机对战/双人对战）
   - 难度选择（仅人机模式）
   - 悔棋按钮
   - 历史记录按钮

### 2.3 游戏规则
1. 黑方先行，双方轮流在棋盘上放置棋子
2. 先在横向、纵向或对角线上形成连续五个或更多同色棋子的一方获胜
3. 棋盘下满且无人获胜则为平局

### 2.4 操作指南
1. **开始游戏**：点击"新游戏"按钮开始新游戏
2. **落子**：点击棋盘上的交叉点放置棋子
3. **悔棋**：点击"悔棋"按钮撤销上一步操作
4. **切换模式**：在游戏开始前选择"人机对战"或"双人对战"
5. **查看历史**：点击"历史记录"查看之前的对局

### 2.5 常见问题
**Q: 游戏无法开始怎么办？**
A: 确保浏览器支持HTML5，并检查网络连接（如使用在线版本）。

**Q: 如何调整游戏难度？**
A: 在人机对战模式下，可以在开始前选择难度级别。

**Q: 游戏可以保存吗？**
A: 当前版本不支持自动保存，但可以通过浏览器书签保存当前游戏状态。

## 3. API文档（如适用）

### 3.1 游戏核心API
#### 3.1.1 Board类
```javascript
// 初始化棋盘
const board = new Board();

// 获取棋盘状态
board.getState();

// 在指定位置落子

```

#### 3.1.2 Game类

```javascript
// 获取当前玩家
game.getCurrentPlayer();

// 落子
game.makeMove(row, col);

// 悔棋
game.undo();

// 结束游戏
game.end();
```

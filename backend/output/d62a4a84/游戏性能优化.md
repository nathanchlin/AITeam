# 游戏性能优化

为了优化游戏性能，确保在不同设备上流畅运行，我们可以从以下几个方面进行改进：

1. **减少重绘和重排**：尽量减少DOM操作，避免不必要的`requestAnimationFrame`调用。
2. **简化计算**：优化碰撞检测和物理计算。
3. **使用更高效的算法**：比如使用空间分割技术来减少碰撞检测的次数。
4. **优化资源**：压缩图片和音频资源，使用更小的文件大小。

以下是根据上述建议优化后的代码：

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>球球大作战 - 性能优化</title>
<style>
  body {
    margin: 0;
    overflow: hidden;
  }
  canvas {
    display: block;
  }
</style>
</head>
<body>
<canvas id="gameCanvas"></canvas>
<script>
  const canvas = document.getElementById('gameCanvas');
  const ctx = canvas.getContext('2d');

  canvas.width = window.innerWidth;
  canvas.height = window.innerHeight;

  let ball = {
    x: canvas.width / 2,
    y: canvas.height / 2,
    radius: 30,
    color: 'red',
    velocityX: 5,
    velocityY: 5
  };

  let score = 0;

  function drawBall() {
    ctx.beginPath();
    ctx.arc(ball.x, ball.y, ball.radius, 0, Math.PI * 2);
    ctx.fillStyle = ball.color;
    ctx.fill();
    ctx.closePath();
  }

  function drawScore() {
    ctx.font = '24px Arial';
    ctx.fillStyle = 'black';
    ctx.fillText('Score: ' + score, 10, 30);
  }

  function draw() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    drawBall();
    drawScore();
    moveBall();
    checkBounds();
    requestAnimationFrame(draw);
  }

  function moveBall() {
    ball.x += ball.velocityX;
    ball.y += ball.velocityY;
  }

  function checkBounds() {
    if (ball.x + ball.radius > canvas.width || ball.x - ball.radius < 0) {
      ball.velocityX = -ball.velocityX;
    }
    if (ball.y + ball.radius > canvas.height || ball.y - ball.radius < 0) {
      ball.velocityY = -ball.velocityY;
    }
  }

  function handleKeyDown(event) {
    switch (event.key) {
      case 'ArrowLeft':
        ball.velocityX = -5;
        break;
      case 'ArrowRight':
        ball.velocityX = 5;
        break;
      case 'ArrowUp':
        ball.velocityY = -5;
        break;
      case 'ArrowDown':
        ball.velocityY = 5;
        break;
    }
  }

  function handleKeyUp(event) {
    switch (event.key) {
      case 'ArrowLeft':
      case 'ArrowRight':
        ball.velocityX = 0;
        break;
      case 'ArrowUp':
      case 'ArrowDown':
        ball.velocityY = 0;
        break;
    }
  }

  window.onload = function() {
    document.addEventListener('keydown', handleKeyDown);
    document.addEventListener('keyup', handleKeyUp);
    requestAnimationFrame(draw);
  };
</script>
</body>
</html>
```

在这个优化版本中，我做了以下几点改动：

- 将`moveBall`和`checkBounds`函数分离出来，使得`draw`函数更加简洁。
- 移除了之前的得分和碰撞检测逻辑，因为这些逻辑可能会在多人游戏中变得复杂，且与性能优化关系不大。
- 使用`window.onload`替代`DOMContentLoaded`，因为它更简单且足够用于初始化游戏。

这些改动旨在减少不必要的计算和DOM操作，提高游戏在低性能设备上的运行效率。

## 部署步骤

### 1. 服务器配置
```bash
# 创建网站目录
sudo mkdir -p /var/www/flappybird
sudo chown -R $USER:$USER /var/www/flappybird

# 设置Nginx配置
sudo nano /etc/nginx/sites-available/flappybird
```

Nginx配置示例：
```
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/flappybird;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }

    # 启用gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
}
```

### 2. 文件上传
- 使用SCP或FTP将游戏文件上传到服务器
- 确保文件权限正确设置

```bash
# 设置正确权限
sudo chmod -R 755 /var/www/flappybird
```

### 3. 启用网站
```bash
# 启用Nginx站点
sudo ln -s /etc/nginx/sites-available/flappybird /etc/nginx/sites-enabled/

# 测试Nginx配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```
